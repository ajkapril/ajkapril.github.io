# Black–Scholes Lab

A browser-based study project for option payoffs, Black–Scholes pricing, Greeks, simulations, delta hedging, and the pricing PDE.

## Files

```txt
projects/black-scholes/
├─ index.html
├─ black-scholes.css
├─ black-scholes.js
├─ math.js
└─ README.md
```

## Current skeleton features

- Light/dark mode
- Module navigation
- Working payoff visualiser
- Working Black–Scholes call/put calculator
- Put-call parity check
- Simple canvas charts
- Placeholder panels for Greeks, GBM, binomial model, delta hedging, and PDE visualisation
